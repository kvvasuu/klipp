Fire an impulse from anywhere in your game, and every camera listening to it reacts. Impulses live in an `ImpulseField`. The shared `impulseField` is enough unless you want separate event streams.

```ts
import { impulseField, ImpulseShapes } from '@kvvasuu/klipp';

function onExplosion(position: [number, number, number]) {
  impulseField.generate({
    position,
    direction: [0, 0.5, 0],
    shape: ImpulseShapes.explosion,
    radius: 5,
    dissipationDistance: 15,
  });
}
```

## Core

```ts
import { ImpulseListenerNoiseCore } from '@kvvasuu/klipp';

camera.addNoise(new ImpulseListenerNoiseCore());
```

It listens to the shared `impulseField` unless you pass another as `field`.

## React Three Fiber

```tsx
import { ImpulseListener } from '@kvvasuu/klipp/react';

<VirtualCamera name="follow" priority={10}>
  <Body.Follow target={playerRef} offset={[0, 3, 8]} />
  <Aim.HardLookAt target={playerRef} />
  <ImpulseListener />
</VirtualCamera>
```

> [!NOTE]
> With `frameloop="demand"`, call `invalidate()` after `generate()`. See [On-demand rendering](/advanced/on-demand-rendering).

`ref` gives you the `ImpulseListenerNoise`.

## Generating an impulse

| Option | Description | Default |
| ------ | ----------- | ------- |
| `position` | Where the impulse happens, in world space. | |
| `direction` | Which way, and how far, the camera gets pushed at the peak. A bigger vector is a stronger kick. | `[0, 0, 0]` |
| `shape` | How the strength changes over time: `ImpulseShapes.recoil`, `bump`, `explosion`, `rumble`, or your own `(t) => number`. | `ImpulseShapes.bump` |
| `duration` | Length in seconds. | `0.4` |
| `radius` | Distance from `position` where the impulse is felt at full strength. | `0` |
| `dissipationDistance` | Distance beyond `radius` over which it fades out. `0` means it's felt everywhere. | `0` |
| `propagationSpeed` | How fast it travels, in units per second, so faraway cameras feel it later. | `Infinity` |
| `channel` | Bitmask to target specific listeners. See `channelMask` below. | `1` |

## Listener settings

| Setting | Description | Default |
| ------- | ----------- | ------- |
| `gain` | Multiplies the impulse strength. `0` mutes this listener. | `1` |
| `shake` | Adds a rattle on top of the push. See below. | |
| `cameraSpace` | Treat `direction` relative to the camera instead of the world. See below. | `false` |
| `channelMask` | Only react to impulses where `channel & channelMask` is not `0`. | `1` |
| `field` | A separate `ImpulseField` to listen to instead of the shared `impulseField`. | `impulseField` |

## Adding a rattle

An impulse on its own only pushes the camera. `shake` adds rotation and jitter that grows and fades with it. It's a [`BasicMultiChannelPerlin`](/noise/basic-multi-channel-perlin) whose `amplitudeGain` follows the impulse strength. React takes its settings instead of the noise itself:

```ts
const shake = new BasicMultiChannelPerlinNoiseCore({ positionAmplitude: [0.1, 0.1, 0.1], rotationAmplitude: [4, 4, 4] });
camera.addNoise(new ImpulseListenerNoiseCore({ shake }));
```

```tsx
<ImpulseListener shake={{ positionAmplitude: [0.1, 0.1, 0.1], rotationAmplitude: [4, 4, 4] }} />
```

## Camera-relative impulses

By default `direction` is in world space, which suits explosions: the camera gets pushed away from where it happened. For recoil or a landing thump, use `cameraSpace` so the same `direction` always kicks the same way on screen:

```ts
impulseField.generate({ position: [0, 0, 0], direction: [0, 0.3, 0.1], shape: ImpulseShapes.recoil });

camera.addNoise(new ImpulseListenerNoiseCore({ cameraSpace: true }));
```

```tsx
<ImpulseListener cameraSpace />
```
