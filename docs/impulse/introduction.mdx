Event-driven, one-shot reactions - an explosion, an impact, a footstep - instead of continuous shake. `impulseField.generate()` fires an event with its own position, direction/strength, and envelope. `ImpulseListener` samples the sum of every still-active event as an additive position offset, plugging into the same stacking Noise slot [`BasicMultiChannelPerlin`](/noise/basic-multi-channel-perlin) uses - mechanically a Noise-slot filler, but its own top-level concept, not a Noise variant.

```tsx
import { impulseField, ImpulseShapes } from '@kvvasuu/klipp';

function onExplosion(position: Vector3) {
  impulseField.generate({
    position,
    direction: [0, 0.5, 0],
    shape: ImpulseShapes.explosion,
    radius: 5,
    dissipationDistance: 15,
  });
}
```

```tsx
<VirtualCamera name="follow-cam" priority={10}>
  <Body.Follow target={playerRef} offset={[0, 3, 8]} damping={0.5} />
  <Aim.HardLookAt target={playerRef} />
  <ImpulseListener />
</VirtualCamera>
```

## Generating an event

`impulseField.generate(options, now?)` - `now` defaults to the real clock, pass it explicitly only in tests for determinism.

| Option                | Type           | Default     | |
| ---------------------- | -------------- | ----------- | - |
| `position`             | `Vector3`      | -           | World-space origin of the event. |
| `direction`            | `Vector3`      | `[0, 0, 0]` | World-space direction **and** strength of the kick - the offset at peak envelope is exactly this vector, not a separately-scaled unit direction. A bigger explosion is a bigger `direction`, not a separate strength field. |
| `shape`                | `ImpulseShape` | `ImpulseShapes.bump` | The envelope's amplitude curve, normalized progress `t` (0..1 over `duration`) in, amplitude out. Named presets - `ImpulseShapes.recoil`/`bump`/`explosion`/`rumble` - or pass your own `(t) => number` for anything else. |
| `duration`             | `number`       | `0.4`       | Seconds `shape` is stretched across. |
| `radius`               | `number`       | `0`         | Distance from `position` within which the event is felt at full strength. |
| `dissipationDistance`  | `number`       | `0`         | Distance beyond `radius` over which strength falls off linearly to `0`. `0` = no falloff, felt at full strength at any distance. |
| `propagationSpeed`     | `number`       | `Infinity`  | World units/second the signal travels outward at, delaying a distant listener like a real sound wave. `Infinity` (default) = felt everywhere instantly. |
| `channel`              | `number`       | `1`         | Bitmask - a listener only reacts if `(channel & listener.channelMask) !== 0`. |


`generate()` is typically called from a physics/gameplay callback - under `frameloop="demand"` that's exactly the kind of mutation [Core Concepts](/getting-started/core-concepts) warns about: call `invalidate()` right after `generate()`, or the impulse won't actually render until something else happens to request a frame.

## `ImpulseListener`

| Prop          | Type                | Default                          | |
| ------------- | ------------------- | --------------------------------- | - |
| `field`       | `ImpulseField`      | shared `impulseField` singleton   | Pass your own instance only for isolated impulse "worlds" (e.g. split-screen with independent explosions per view). |
| `channelMask` | `number`            | `1`                                | Only reacts to events where `(event.channel & channelMask) !== 0`. |
| `gain`        | `number`            | `1`                                | Multiplies the sampled offset. `0` mutes this listener entirely. |
| `shake`       | `ImpulseShakeProps` | none                               | Secondary rattle, riding on top of the kick - see below. |
| `cameraSpace` | `boolean`           | `false`                            | Rotates the sampled offset by the camera's current orientation - see below. |

## Adding rotation with `shake`

The kick itself (`direction` shaped by `shape`) is position-only. For the rattle-and-shudder look real impacts have - explosions and rumbles pitching the camera, not just pushing it - pass `shake`: the same props as [`<Noise.BasicMultiChannelPerlin>`](/noise/basic-multi-channel-perlin), minus `amplitudeGain` (`ImpulseListener` drives that itself, every frame, from the impulse's current strength - the shake automatically swells with the kick and fades out with it). You tune `positionAmplitude`/`rotationAmplitude`/`frequency` for what it looks like at full strength, same as configuring any other Noise.

```tsx
<ImpulseListener shake={{ positionAmplitude: [0.1, 0.1, 0.1], rotationAmplitude: [4, 4, 4] }} />
```

## World-space vs `cameraSpace`

`direction` is a world-space vector by default - right for an explosion that should push the camera away from wherever it actually happened, regardless of which way the camera is facing. For an event that's always about the camera itself - weapon recoil, a landing thump - `cameraSpace` reinterprets the same `direction` relative to the camera's current orientation instead, so a fixed vector always kicks the same way no matter where the camera is or looks:

```tsx
function onFire() {
  impulseField.generate({ position: [0, 0, 0], direction: [0, 0.3, 0.1], shape: ImpulseShapes.recoil });
}

<ImpulseListener cameraSpace />
```

## `ref`

```tsx
const listenerRef = useRef<ImpulseListenerNoise>(null);
```

Gives you the underlying `ImpulseListenerNoise` - read or write `.field`/`.channelMask`/`.gain`/`.shake`/`.cameraSpace` directly.
