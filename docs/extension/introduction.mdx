Extensions tweak a shot once the Body and Aim are done. You can add as many as you like to one virtual camera, and they run in the order they were added. `addExtension` returns a function that removes one.

## Which one?

| Extension | Use it for |
| --------- | ---------- |
| [`GroupFraming`](/extension/group-framing) | Keeping several targets in view by moving the camera closer or farther. |
| [`Lens`](/extension/lens) | Changing `fov`, `near` and `far`, with damping. |

```ts
import { GroupFramingExtension, LensExtension } from '@kvvasuu/klipp';

camera.addExtension(new GroupFramingExtension(members, 'groupCenter', { padding: 1 }));
const removeLens = camera.addExtension(new LensExtension({ fov: 40, fovDamping: 0.5 }));
```

```ts
import { LensExtension } from '@kvvasuu/klipp';
import { GroupFramingExtensionThree, TargetGroup } from '@kvvasuu/klipp/three';

camera.addExtension(new GroupFramingExtensionThree(new TargetGroup([{ target: a }, { target: b }]), { padding: 1 }));
const removeLens = camera.addExtension(new LensExtension({ fov: 40, fovDamping: 0.5 }));
```

```tsx
import { Extension } from '@kvvasuu/klipp/react';

<VirtualCamera name="party" priority={10}>
  <Body.Follow target={leaderRef} offset={[0, 4, 10]} />
  <Aim.HardLookAt target={leaderRef} />
  <Extension.GroupFraming members={[{ target: aRef }, { target: bRef }]} padding={1} />
  <Extension.Lens fov={40} fovDamping={0.5} />
</VirtualCamera>
```
