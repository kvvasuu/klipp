---
title: GroupFraming
description: Moves the camera closer or farther to keep several targets in view.
nav: 41
---

Keeps every member on screen. It places the camera in line with the group's center, along the camera's current view direction, at the distance where every member fits. By default it never moves the camera closer than the Body placed it; with `fitMode="rigid"` it always sits at exactly that distance, so it also moves in as the group gets smaller.

It doesn't rotate the camera, so pair it with an Aim that already looks at the group.

```tsx
<VirtualCamera name="party" priority={10}>
  <Body.Follow target={leaderRef} offset={[0, 4, 10]} />
  <Aim.HardLookAt target={leaderRef} />
  <Extension.GroupFraming
    members={[{ target: aRef }, { target: bRef, radius: 2 }]}
    padding={1}
    damping={0.5}
  />
</VirtualCamera>
```

## Props

| Prop | Description | Default |
| ---- | ----------- | ------- |
| `members` | The targets to keep in view. See below. | |
| `padding` | Extra space around the members, in world units. | `0` |
| `fitMode` | `'ceiling'` never moves the camera closer than the Body placed it. `'rigid'` always sits at exactly the distance that fits the group. | `'ceiling'` |
| `framingMode` | Which screen dimensions to fit: `'horizontal'`, `'vertical'` or `'horizontalAndVertical'`. | `'horizontalAndVertical'` |
| `minDistance` | Closest the camera may get to the group. | `0` |
| `maxDistance` | Farthest `GroupFraming` will move the camera away from the group. | `Infinity` |
| `damping` | Seconds to catch up with the right distance. See [Damping](/getting-started/core-concepts#damping). | `0` |
| `maxSpeed` | Maximum catch-up speed, in units per second. | `Infinity` |
| `screenPosition` | Shifts the view without moving the camera, for example to leave room for UI. `[0, 0]` is centered. | `[0, 0]` |
| `positionMode` | How the group's center, which the camera lines up with, is computed: `'groupCenter'` (center of the bounds) or `'groupAverage'` (weighted average of positions). | `'groupCenter'` |
| `debug` | Draws the padding on screen. See [Debugging](/debugging/introduction). | `false` |

## Members

| Field | Description | Default |
| ----- | ----------- | ------- |
| `target` | The member. See [Targets](/getting-started/core-concepts#targets). | |
| `weight` | Influence on the center in `'groupAverage'` mode. | `1` |
| `radius` | The member's radius, so its edge stays in view instead of its center. | `0` |
| `size` | The member's box size, used instead of `radius`. Measured automatically for meshes. | |

## `ref`

`ref` gives you the `GroupFramingExtension`. If a member's shape changes, call `recalculateSize()` to measure it again.
