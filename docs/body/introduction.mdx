A Body decides where the camera is. Where it looks is up to the [Aim](/aim/introduction). Each virtual camera has at most one Body.

## Core

```ts
import { FollowBodyCore, HardLookAtAimCore } from '@kvvasuu/klipp';

camera.body = new FollowBodyCore(player, { offset: [0, 3, 8], damping: 0.5 });
camera.aim = new HardLookAtAimCore(player);
```

Setting `camera.body` replaces any previous Body.

## React Three Fiber

```tsx
import { VirtualCamera, Body, Aim } from '@kvvasuu/klipp/react';

<VirtualCamera name="follow" priority={10}>
  <Body.Follow target={playerRef} offset={[0, 3, 8]} damping={0.5} />
  <Aim.HardLookAt target={playerRef} />
</VirtualCamera>
```

## Which one?

| Body | Use it for |
| ---- | ---------- |
| [`HardLockToTarget`](/body/hard-lock-to-target) | Placing the camera exactly on a target: first person, a camera mounted on something, a fixed spot. |
| [`Follow`](/body/follow) | Keeping a fixed offset from a target: chase cameras, third person. |
| [`PositionComposer`](/body/position-composer) | Keeping a target at a spot on screen: top-down, side-scrollers, anything with a fixed rotation. |
| [`CameraControls`](/body/camera-controls) | Letting the user orbit, pan and zoom. |

Without a Body the camera stays at its starting position, [`initialState`](/api/virtual-camera#initialstate).
