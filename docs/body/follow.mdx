title: Follow

Keeps the camera at `offset` from the target. By default the offset turns with the target, so a chase camera stays behind a character as it turns.

```tsx
<VirtualCamera name="chase" priority={10}>
  <Body.Follow target={playerRef} offset={[0, 3, 8]} damping={0.5} />
  <Aim.HardLookAt target={playerRef} />
</VirtualCamera>
```

## Props

| Prop | Description | Default |
| ---- | ----------- | ------- |
| `target` | What to follow. See [Targets](/getting-started/core-concepts#targets). | |
| `offset` | Where the camera sits relative to the target. | `[0, 0, 10]` |
| `damping` | Seconds to catch up with the target. `0` is instant. See [Damping](/getting-started/core-concepts#damping). | `0` |
| `maxSpeed` | Maximum catch-up speed, in units per second. | `Infinity` |
| `bindingMode` | How the offset turns with the target. See below. | `BindingModes.lockToTarget` |

## `bindingMode`

```tsx
import { BindingModes } from '@kvvasuu/klipp';

<Body.Follow target={planeRef} offset={[0, 2, 10]} bindingMode={BindingModes.lockToTargetWithWorldUp} />
```

| Mode | The offset turns with the target's |
| ---- | ---------------------------------- |
| `lockToTarget` | full rotation, including roll. |
| `lockToTargetNoRoll` | yaw and pitch, but never rolls. |
| `lockToTargetWithWorldUp` | yaw only. Good for flying or jumping targets. |
| `lockToTargetOnAssign` | rotation at the moment `target` is set, then stays fixed. |
| `worldSpace` | nothing. The offset is always in world space. |

With a fixed-point target like `[0, 1, 0]` there's no rotation to follow, so the offset is always in world space.

The binding mode also tells Aims like [`HardLookAt`](/aim/hard-look-at) which way is up, so with `lockToTarget` the camera rolls along with the target, and with `lockToTargetWithWorldUp` it never does.

`ref` gives you the `FollowBody`.
