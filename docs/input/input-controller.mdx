---
title: InputController
description: Maps mouse and touch drags onto a component's axes.
nav: 61
---

Place it inside a component that has axes, like [`PanTilt`](/aim/pan-tilt), and it finds them automatically.

```tsx
<Aim.PanTilt>
  <InputController
    mouseButtons={{ right: { axes: { x: 'pan', y: 'tilt' }, gain: 0.15 } }}
    touches={{ one: { axes: { x: 'pan', y: 'tilt' }, gain: 0.15 } }}
    suppressContextMenu
  />
</Aim.PanTilt>
```

Input is only read while its camera is on screen.

## Props

| Prop | Description | Default |
| ---- | ----------- | ------- |
| `mouseButtons` | What each mouse button drives: `{ left, right, middle }`. | |
| `touches` | What each finger count drives: `{ one, two, three }`. | |
| `enabled` | Turns input on or off. | `true` |
| `waitForBlend` | Ignore input until the blend into this camera has finished. | `true` |
| `suppressContextMenu` | Disable the right-click menu on the canvas. | `false` |
| `interactiveArea` | Only start drags inside part of the canvas, as a normalized rectangle. | whole canvas |
| `lockTouchAxis` | For two-finger gestures, pick either pinch or rotate instead of both. | `false` |
| `target` | A ref to something else with axes to control (for example a `PanTiltAim`), instead of the component it's placed in. | parent |

## Mapping a source

Each button or finger count takes the same config:

```ts
{
  axes: { x: 'pan', y: 'tilt' }, // which axis receives the horizontal and vertical drag
  gain: 0.15,                    // multiplier from pixels to axis units
  invert: { y: true },           // flip one or both directions, or `true` for both
}
```

## Pointer lock

For mouse look without holding a button, request pointer lock through the `ref`. While locked, mouse movement goes to `mouseButtons.left`:

```tsx
const input = useRef<InputAxisController>(null);

<InputController ref={input} mouseButtons={{ left: { axes: { x: 'pan', y: 'tilt' } } }} />;

// in a click handler
input.current.inputSystem.requestPointerLock();
input.current.inputSystem.exitPointerLock();
```

## Raw input

`ref.current.lastInput` holds this frame's raw deltas, for example `wheelDeltaY`, `touchPinchDelta` or `leftDx`, if you want to handle something yourself:

```tsx
useFrame(() => {
  zoom += input.current.lastInput.wheelDeltaY * 0.01;
});
```
