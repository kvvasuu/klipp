Maps mouse buttons and finger counts onto axes.

## Core

`InputAxisController` from `@kvvasuu/klipp/dom` takes the axes themselves. Every source has to be listed, `null` for unused ones:

```ts
import { InputAxisController } from '@kvvasuu/klipp/dom';

const input = new InputAxisController({
  mouseButtons: { left: null, right: { axes: { x: aim.pan, y: aim.tilt }, gain: 0.15 }, middle: null },
  touches: { one: { axes: { x: aim.pan, y: aim.tilt }, gain: 0.15 }, two: null, three: null },
});
input.inputSystem.suppressContextMenu = true;
input.connect(canvas);
klipp.registerUpdate(() => input.update());
```

Connect it while its camera is on screen and `disconnect()` it otherwise, so several cameras don't react to the same drag. `input.enabled = false` keeps it connected but ignores input.

## React Three Fiber

Place `<InputController>` inside a piece that has axes, like [`PanTilt`](/aim/pan-tilt), and it finds them by name. Input is only read while its camera is on screen.

```tsx
<Aim.PanTilt>
  <InputController
    mouseButtons={{ right: { axes: { x: 'pan', y: 'tilt' }, gain: 0.15 } }}
    touches={{ one: { axes: { x: 'pan', y: 'tilt' }, gain: 0.15 } }}
    suppressContextMenu
  />
</Aim.PanTilt>
```

`ref` gives you the `InputAxisController`.

## Settings

| Setting | Description | Default |
| ------- | ----------- | ------- |
| `mouseButtons` | What each mouse button drives: `{ left, right, middle }`. | |
| `touches` | What each finger count drives: `{ one, two, three }`. | |
| `enabled` | Turns input on or off. | `true` |
| `suppressContextMenu` | Disable the right-click menu on the canvas. On `inputSystem` on the core. | `false` |
| `interactiveArea` | Only start drags inside part of the canvas, as a normalized rectangle. On `inputSystem` on the core. | whole canvas |
| `lockTouchAxis` | For two-finger gestures, pick either pinch or rotate instead of both. On `inputSystem` on the core. | `false` |
| `waitForBlend` | React only. Ignore input until the blend into this camera has finished. | `true` |
| `target` | React only. A ref to something else with axes to control (for example a `PanTiltAim`), instead of the piece it's placed in. | parent |

## Mapping a source

Each button or finger count takes the same config:

```ts
{
  axes: { x: 'pan', y: 'tilt' }, // which axis receives the horizontal and vertical drag; the axes themselves on the core
  gain: 0.15,                    // multiplier from pixels to axis units
  invert: { y: true },           // flip one or both directions, or `true` for both
}
```

## Pointer lock

For mouse look without holding a button, request pointer lock. While locked, mouse movement goes to `mouseButtons.left`:

```tsx
const input = useRef<InputAxisController>(null);

<InputController ref={input} mouseButtons={{ left: { axes: { x: 'pan', y: 'tilt' } } }} />;

// in a click handler
input.current.inputSystem.requestPointerLock();
input.current.inputSystem.exitPointerLock();
```

On the core, call the same methods on your controller's `inputSystem`.

## Raw input

`lastInput` holds this frame's raw deltas, for example `wheelDeltaY`, `touchPinchDelta` or `leftDx`, if you want to handle something yourself:

```tsx
useFrame(() => {
  zoom += input.current.lastInput.wheelDeltaY * 0.01;
});
```
