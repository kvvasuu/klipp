An `InputAxis` is one value the user controls, like `pan` or `tilt` on [`PanTilt`](/aim/pan-tilt). [`<InputController>`](/input/input-controller) feeds it drags, but you can drive it from code as well:

```ts
const aim = useRef<PanTiltAim>(null);

aim.current.pan.applyDelta(5); // turn by 5°
aim.current.pan.value;         // read the current value
```

## Fields

| Field | Description | Default |
| ----- | ----------- | ------- |
| `value` | The current value. | `0` |
| `center` | The value `recentering` returns to. | `0` |
| `range` | `[min, max]` limits, or `null` for none. | `null` |
| `wrap` | Loop around at the edges of `range` instead of stopping. | `false` |
| `damping` | Seconds to catch up with the input. See [Damping](/getting-started/core-concepts#damping). | `0` |
| `maxSpeed` | Maximum change per second. | `Infinity` |
| `recentering` | Return to `center` after a while without input. See below. | off |
| `autoNormalize` | With `wrap` on, bring `value` back inside `range` after each drag. | `false` |

All fields can be changed at any time.

## Recentering

```ts
axis.recentering = { enabled: true, wait: 1, time: 0.5 };
```

Once the user lets go and `wait` seconds pass without input, the value eases back to `center` over `time` seconds. Any new input cancels it.

## Using it on its own

`InputAxis` has no React dependency. Call `update(dt)` once per frame:

```ts
import { InputAxis } from '@kvvasuu/klipp';

const zoom = new InputAxis(10, 10, [2, 20]); // value, center, range

zoom.applyDelta(-1);
zoom.update(dt);
zoom.value;
```
