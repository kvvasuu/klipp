Some pieces can be controlled by the user, like [`PanTilt`](/aim/pan-tilt). They expose **axes** (`pan`, `tilt`), and an [input controller](/input/input-controller) maps mouse and touch drags onto those axes.

Each axis is an [`InputAxis`](/input/input-axis), a value with limits, wrapping, damping and optional recentering. You can also drive an axis from your own code, for example in a cutscene.

The examples below read as: dragging with the right mouse button, or with one finger, moves `pan` horizontally and `tilt` vertically.

`InputAxisController` from `@kvvasuu/klipp/dom` reads the mouse and touch, and takes the axes themselves:

```ts
import { InputAxisController } from '@kvvasuu/klipp/dom';

const input = new InputAxisController({
  mouseButtons: { left: null, right: { axes: { x: aim.pan, y: aim.tilt } }, middle: null },
  touches: { one: { axes: { x: aim.pan, y: aim.tilt } }, two: null, three: null },
});
klipp.whileOnScreen(camera, () => {
  input.connect(canvas);
  return () => input.disconnect();
});
klipp.registerUpdate(() => input.update()); // reads input before the cameras run
```

Without a DOM, feed the axes from any source with `axis.applyDelta(delta)`.

`InputAxisController` from `@kvvasuu/klipp/dom` reads the mouse and touch, and takes the axes themselves:

```ts
import { InputAxisController } from '@kvvasuu/klipp/dom';

const input = new InputAxisController({
  mouseButtons: { left: null, right: { axes: { x: aim.pan, y: aim.tilt } }, middle: null },

klipp.whileOnScreen(camera, () => {
  input.connect(renderer.domElement);
```

An `<InputController>` placed inside the piece finds its axes by name:

```tsx
import { Aim, InputController } from '@kvvasuu/klipp/react';

<VirtualCamera name="look-around" priority={10}>
  <Aim.PanTilt>
    <InputController
      mouseButtons={{ right: { axes: { x: 'pan', y: 'tilt' } } }}
      touches={{ one: { axes: { x: 'pan', y: 'tilt' } } }}
    />
  </Aim.PanTilt>
</VirtualCamera>
```
