A virtual camera describes one shot. Its pieces decide where the camera is and where it looks, and its `priority` decides when it's on screen.

## Choosing the winner

- The active camera with the highest `priority` wins.
- On a tie, the camera that was added, or set active, most recently wins.
- To switch shots, change `priority`, or turn a camera on or off. Either one triggers a blend.

## Members

| Member | Description |
| ------ | ----------- |
| `body`, `aim` | The Body and Aim. Setting one replaces the previous. |
| `addExtension(piece)`, `addNoise(piece)` | Adds an Extension or Noise. They stack, in the order added. Each returns a function that removes it. |
| `name`, `priority`, `active`, `hints` | The settings below, changeable at any time. |
| `state` | The camera's own shot, written by its pieces every frame. |

## Settings

| Setting | Description | Default |
| ------- | ----------- | ------- |
| `name` | Unique name. Used by [custom blends](/blending/introduction#custom-blends) and [events](/api/events). | required |
| `priority` | The active camera with the highest priority is on screen. | `0`, required in React |
| `active` | Whether this camera takes part at all. `false` also stops its pieces from running. Turning it back on starts it fresh. | `true` |
| `hints` | Changes the shape of blends in and out of this camera. See [Blend hints](/blending/introduction#blend-hints). | `BlendHints.none` |
| `initialState` | Starting pose, applied once. See below. | the real camera's pose |

## `initialState`

Sets where the camera starts. Useful for a camera without a Body or Aim, since whatever you set here simply stays put.

It takes any camera state field, most commonly `position`, `quaternion` and `fov`. Pieces with damping ease in from it on the camera's first activation instead of snapping. In three.js and React, vectors also accept a `Vector3` or a single number, and `quaternion` a `Quaternion`.

const follow = klipp.addCamera('follow', { priority: 10 });

```tsx
import { VirtualCamera, Body, Aim } from '@kvvasuu/klipp/react';

<VirtualCamera name="follow" priority={10}>
  <Body.Follow target={playerRef} offset={[0, 3, 8]} />
  <Aim.HardLookAt target={playerRef} />
</VirtualCamera>

<VirtualCamera name="map" priority={20} active={mapOpen}>...</VirtualCamera>
```

`ref` gives you the camera, with the members above.

**`initialState`**

```tsx
<VirtualCamera name="fixed" priority={10} initialState={{ position: [0, 10, 10], fov: 35 }}>
  <Aim.HardLookAt target={playerRef} />
</VirtualCamera>
```

**`<VirtualCamera.Events>`**

Listens to transitions involving this camera only. See [Events](/api/events).

```tsx
<VirtualCamera name="boss" priority={50} active={bossFight}>
  <VirtualCamera.Events onBlendFinished={() => startBossMusic()} />
</VirtualCamera>
```
