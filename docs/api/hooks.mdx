Hooks are React-only. With the core, read the same values from [`KlippCore`](/api/klipp#core).

## `useIsActiveVirtualCamera`

Whether the nearest `<VirtualCamera>` is the current winner. Turns `true` as soon as the blend into it starts.

```tsx
function Hud() {
  const isActive = useIsActiveVirtualCamera();
  return isActive ? <Crosshair /> : null;
}

<VirtualCamera name="aim-down-sights" priority={20} active={aiming}>
  <Hud />
</VirtualCamera>
```

## `useIsLiveVirtualCamera`

Whether the nearest `<VirtualCamera>` is fully on screen. Turns `true` only once the blend into it has finished.

```tsx
const isLive = useIsLiveVirtualCamera();
```

## `useVirtualCamera`

The camera behind the nearest `<VirtualCamera>`, with its pieces and raw `state`. Mostly needed for [custom pieces](/advanced/custom-components). It has the same members as a [core camera](/api/virtual-camera#core).

```tsx
const camera = useVirtualCamera();
camera.state; // the camera's raw state
```

## `useKlipp`

The `Klipp` behind the nearest `<Klipp>`, which knows about every camera. It has the same members as [`KlippCore`](/api/klipp#core).

```tsx
const klipp = useKlipp();

klipp.activeCameraId; // the current winner
klipp.liveCameraId;   // the camera fully on screen
klipp.isBlending;     // whether a blend is in progress
```
