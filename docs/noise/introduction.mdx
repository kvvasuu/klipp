title: Noise
description: Adds camera shake on top of the shot.
nav: 50
---

Noise shakes the camera on top of everything else, so the shot stays framed correctly underneath. You can add as many as you like to one `<VirtualCamera>`.

```tsx
import { Noise } from '@kvvasuu/klipp/react';

<VirtualCamera name="follow" priority={10}>
  <Body.Follow target={playerRef} offset={[0, 3, 8]} />
  <Aim.HardLookAt target={playerRef} />
  <Noise.BasicMultiChannelPerlin positionAmplitude={[0.1, 0.1, 0]} rotationAmplitude={[0.5, 0.5, 0]} />
</VirtualCamera>
```

| Noise | Use it for |
| ----- | ---------- |
| [`BasicMultiChannelPerlin`](/noise/basic-multi-channel-perlin) | Continuous shake: handheld cameras, engines, earthquakes. |
| [`ImpulseListener`](/impulse/introduction) | One-off shakes from events: explosions, hits, recoil. |
