Noise shakes the camera on top of everything else, so the shot stays framed correctly underneath. You can add as many as you like to one virtual camera. Noise runs after every Extension, and `addNoise` returns a function that removes one.

## Which one?

| Noise | Use it for |
| ----- | ---------- |
| [`BasicMultiChannelPerlin`](/noise/basic-multi-channel-perlin) | Continuous shake: handheld cameras, engines, earthquakes. |
| [`ImpulseListener`](/impulse/introduction) | One-off shakes from events: explosions, hits, recoil. |
