[`PositionComposer`](/body/position-composer), [`RotationComposer`](/aim/rotation-composer), and [`GroupFraming`](/extension/group-framing) all take a `debug` prop that draws their zones as bordered boxes directly over the canvas, dimming everything outside them, plus a crosshair marking `screenPosition` itself.

```tsx
<Body.PositionComposer target={playerRef} deadZone={[0.4, 0.4]} hardLimit={[0.7, 0.7]} debug />
```

| Component           | Draws |
| -------------------- | ----- |
| `PositionComposer`   | `hardLimit` (red) and `deadZone` (green), if either is non-zero, plus a crosshair at `screenPosition`. |
| `RotationComposer`   | Same as `PositionComposer` - `hardLimit`/`deadZone`/crosshair. |
| `GroupFraming`       | `padding` (blue), inset from the frame edges. No crosshair (`screenPosition` there shifts the whole frustum, not a point to compose toward). |

`GroupFraming`'s box marks the `padding` boundary for a dimensionless point, not any specific member's own visual size - a member with a real `radius` sits somewhat inside the drawn line, since its own radius (like `padding`) also pushes the camera back. It's a guide for where the margin starts, not a pixel-exact outline of every member's silhouette.

## Crosshair

A full-viewport vertical + horizontal line through `screenPosition` - a fixed reference line makes it much easier to see a target drift off `screenPosition` than eyeballing it against the raw scene alone, especially useful alongside [Lookahead](/body/position-composer#lookahead) where the composed point is expected to lead the target rather than sit exactly on it.

## Timing

The overlay appears the instant its `<VirtualCamera>` wins arbitration and disappears the instant it loses, independent of any blend in progress.

## Styling

Each drawn element gets an ordinary CSS class - `klipp-debug-deadzone`, `klipp-debug-hardlimit`, `klipp-debug-groupframing`, `klipp-debug-crosshair` - styled by a stylesheet klipp injects once (idempotently, into `document.head`) with sensible defaults. Override colors, border width, or anything else with your own CSS at the same or higher specificity:

```css
.klipp-debug-deadzone { border-color: lime; border-width: 4px; }
.klipp-debug-hardlimit { border-color: orange; }
.klipp-debug-crosshair { background: cyan; }
```

## Implementation

Plain, imperative DOM manipulation (`document.createElement`/`appendChild`), not JSX or a `react-dom` portal - inserted as a sibling of the canvas itself (`state.gl.domElement.parentElement`).
