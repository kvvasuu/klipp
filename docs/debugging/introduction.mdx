## Framing zones

[`PositionComposer`](/body/position-composer), [`RotationComposer`](/aim/rotation-composer) and [`GroupFraming`](/extension/group-framing) can draw their zones on top of the canvas.

| Piece | Draws |
| ----- | ----- |
| `PositionComposer`, `RotationComposer` | `deadZone` in green, `hardLimit` in red, and a crosshair at `screenPosition`. |
| `GroupFraming` | `padding` in blue. |

Each element has a CSS class you can restyle: `klipp-debug-deadzone`, `klipp-debug-hardlimit`, `klipp-debug-groupframing` and `klipp-debug-crosshair`.

```css
.klipp-debug-deadzone {
  border-color: lime;
}
```

## Camera frustums

A frustum helper draws a camera in the scene, so you can see where an inactive camera is and what it's looking at. Every camera's `state` holds what it needs: `position`, `quaternion`, `fov`, `near` and `far`.

**Framing zones**

Draw them with `DebugOverlay` from `@kvvasuu/klipp/dom`:

```ts
import { composerDebugZones } from '@kvvasuu/klipp';
import { DebugOverlay } from '@kvvasuu/klipp/dom';

const overlay = new DebugOverlay();
overlay.connect(canvas.parentElement!);
overlay.render(composerDebugZones(body.screenPosition, body.deadZone, body.hardLimit), body.screenPosition);
```

`composerDebugZones` turns a composer's settings into the same boxes the React components draw. Call `render` again whenever the zones change, and `disconnect()` to remove the overlay. For group framing, `groupFramingPaddingBox` gives the size of the padding boundary.

**Framing zones**

Draw them with `DebugOverlay` from `@kvvasuu/klipp/dom`:

```ts
import { composerDebugZones } from '@kvvasuu/klipp';
import { DebugOverlay } from '@kvvasuu/klipp/dom';

const overlay = new DebugOverlay();
overlay.connect(renderer.domElement.parentElement!);
overlay.render(composerDebugZones(body.screenPosition, body.deadZone, body.hardLimit), body.screenPosition);
```

`composerDebugZones` turns a composer's settings into the same boxes the React components draw. Call `render` again whenever the zones change, and `disconnect()` to remove the overlay. For group framing, `groupFramingPaddingBox` gives the size of the padding boundary.


**Camera frustums**

`CameraFrustumHelper` is a `CameraHelper` that follows a virtual camera's `state`. Its `maxDistance` sets how far the frustum is drawn, `1` by default:

```ts
import { CameraFrustumHelper } from '@kvvasuu/klipp/three';

const helper = new CameraFrustumHelper();
scene.add(helper);

// every frame, after klipp.update
helper.sync(securityCam.state, innerWidth / innerHeight);
```

**Framing zones**

Add the `debug` prop. The zones show while their camera is the winner:

```tsx
<Body.PositionComposer target={playerRef} deadZone={[0.4, 0.4]} hardLimit={[0.7, 0.7]} debug />
```

**Camera frustums**

Place `<CameraFrustumHelper>` inside the `<VirtualCamera>` you want to see:

```tsx
import { CameraFrustumHelper } from '@kvvasuu/klipp/react';

<VirtualCamera name="security-cam" priority={5}>
  <Body.HardLockToTarget target={[5, 4, 5]} />
  <Aim.HardLookAt target={doorRef} />
  <CameraFrustumHelper color="orange" />
</VirtualCamera>
```

| Prop | Description | Default |
| ---- | ----------- | ------- |
| `color` | Color of the helper. | three.js defaults |
| `maxDistance` | How far the frustum is drawn. | `1` |
| `hideWhenLive` | Hide it while this camera is on screen. | `true` |

`ref` gives you the `THREE.CameraHelper`.
