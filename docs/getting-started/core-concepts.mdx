## Virtual cameras

A [`<VirtualCamera>`](/api/virtual-camera) is a shot you might want to show. You can mount as many as you like. [`<Klipp>`](/api/klipp) decides which one is on screen:

- the **active** camera with the highest `priority` wins,
- `active={false}` takes a camera out of the running completely,
- when the winner changes, klipp [blends](/blending/introduction) from the old shot to the new one.

```tsx
<Klipp>
  <VirtualCamera name="gameplay" priority={10}>...</VirtualCamera>
  <VirtualCamera name="dialogue" priority={20} active={isTalking}>...</VirtualCamera>
</Klipp>
```

## Building a shot

Each camera is made of up to four kinds of pieces, which run in this order every frame:

| Piece | What it does | How many | Examples |
| ----- | ------------ | -------- | -------- |
| [Body](/body/introduction) | Moves the camera | one | `Follow`, `PositionComposer` |
| [Aim](/aim/introduction) | Rotates the camera | one | `HardLookAt`, `RotationComposer` |
| [Extension](/extension/introduction) | Adjusts the finished shot | any | `GroupFraming`, `Lens` |
| [Noise](/noise/introduction) | Adds shake on top | any | `BasicMultiChannelPerlin`, `ImpulseListener` |

Body and Aim are independent, so a camera can follow one object while looking at another:

```tsx
<VirtualCamera name="side-view" priority={10}>
  <Body.Follow target={carRef} offset={[6, 1, 0]} />
  <Aim.HardLookAt target={finishLineRef} />
</VirtualCamera>
```

Every piece is optional. A camera without an Aim keeps its starting rotation, which is handy for top-down or side-scrolling games.

## Targets

Every `target` prop accepts the same things:

```tsx
<Aim.HardLookAt target={playerRef} />   // a ref to an Object3D
<Aim.HardLookAt target={player} />      // an Object3D
<Aim.HardLookAt target={[0, 1, 0]} />   // a fixed point, like <mesh position>
```

Objects are tracked live, including their rotation. A ref that isn't mounted yet, or `null`, is simply ignored until it resolves.

## Damping

Most pieces take a `damping` prop that makes them ease toward their goal instead of snapping to it. It's a time in seconds: `0` is instant, `0.5` feels smooth, `2` feels heavy.

```tsx
<Body.Follow target={playerRef} damping={0.5} />
```

Pass `{ into, from }` to ease differently while the gap is growing (`into`) and while it's closing again (`from`):

```tsx
<Body.Follow target={playerRef} damping={{ into: 0.2, from: 1 }} />
```

Next to `damping` you'll usually find `maxSpeed`, which caps how fast the camera may move while catching up.

## Refs

Every Body, Aim, Extension and Noise gives you the class that does the actual work through `ref`. Use it to read values, or to change them every frame without re-rendering:

```tsx
const body = useRef<FollowBody>(null);

useFrame(() => {
  body.current.offset.z = zoom;
});

<Body.Follow ref={body} target={playerRef} />;
```
