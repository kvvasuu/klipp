```bash
npm install @kvvasuu/klipp
```

klipp has one entry point per layer. Each one only needs the libraries it adapts to, and all of them are optional peer dependencies:

| Entry point | What's in it | Install as well |
| ----------- | ------------ | --------------- |
| `@kvvasuu/klipp` | The core: `Klipp`, `VirtualCamera`, every piece as a class, and the data and functions underneath. | nothing |
| `@kvvasuu/klipp/three` | The core classes for three.js, ending in `Three`: they read `Object3D` targets and drive a `PerspectiveCamera`. | `three` |
| `@kvvasuu/klipp/react` | React Three Fiber components, built on the three.js classes. | `three`, `react`, `@react-three/fiber` |
| `@kvvasuu/klipp/dom` | Mouse, touch and wheel input, and debug overlays. | nothing, runs in a browser |

Vectors in the core are plain arrays from [`math`](https://github.com/pmndrs/math): `[x, y, z]`, and quaternions `[x, y, z, w]`. It comes with klipp; add it to your own dependencies to import its `vec3` and `quat` functions.

Constants like `BlendCurves`, `BindingModes` and `BlendHints` come from the core in every layer.

[`CameraControls`](/body/camera-controls) is built on the `camera-controls` library, so it lives in its own entry points and only ends up in your bundle if you use it.
