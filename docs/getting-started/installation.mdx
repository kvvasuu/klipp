```bash
npm install @kvvasuu/klipp
```

klipp is built with React Three Fiber in mind, but its engine has no React dependency, so you can use it in a plain three.js project too.

## React Three Fiber

Almost everything you need comes from `@kvvasuu/klipp/react`:

```tsx
import { Klipp, VirtualCamera, Body, Aim } from '@kvvasuu/klipp/react';
```

Constants, types and plain classes (`BlendCurves`, `BindingModes`, `impulseField`, `FollowBody`, ...) come from the main entry:

```tsx
import { BlendCurves, BindingModes } from '@kvvasuu/klipp';
```

## Vanilla three.js

The main entry `@kvvasuu/klipp` only needs `three`. The React components are thin wrappers around classes you can use directly:

```ts
import { Vector3 } from 'three';
import { KlippCore, VirtualCameraController, FollowBody, HardLookAtAim, createCameraState, applyCameraState } from '@kvvasuu/klipp';

const core = new KlippCore();

const state = createCameraState();
const follow = new VirtualCameraController('follow');
follow.registerBody(new FollowBody(player, new Vector3(0, 3, 8), 0.5).update);
follow.registerAim(new HardLookAtAim(player).update);
core.registerCamera({ id: 'follow', priority: 10, state });

let justActivated = true;

function onFrame(dt) {
  follow.update(state, dt, justActivated);
  justActivated = false;
  applyCameraState(camera, core.tick(dt), width, height);
}
```

## CameraControls

[`CameraControls`](/body/camera-controls) lives in its own entry point, so `camera-controls` only ends up in your bundle if you use it:

```bash
npm install camera-controls
```

```tsx
import { CameraControls } from '@kvvasuu/klipp/react/camera-controls';
```
