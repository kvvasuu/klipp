This guide builds a camera that follows a moving box, then adds a second shot and switches between the two.

The core works with any renderer. Where the code touches yours, it says `engine`.

<Steps>

<Step>Create klipp</Step>

```ts title="main.ts"
import { KlippCore } from '@kvvasuu/klipp';

const klipp = new KlippCore();
klipp.setSize(canvas.width, canvas.height);
```

`setSize` matters for pieces that frame by screen position, like the composers. Call it again whenever the viewport resizes.

<Step>Add a moving target</Step>

The core doesn't read your scene. A target is a `TargetPose` you keep up to date. After `update`, `klipp.shot` holds the shot to put on your camera:

```ts
import { vec3 } from 'math';
import { createTargetPose } from '@kvvasuu/klipp';

const player = createTargetPose();

function frame(dt: number) {
  const t = engine.time;
  vec3.set(player.position, Math.sin(t) * 4, 0.5, Math.cos(t) * 4);
  engine.box.setPosition(player.position);

  klipp.update(dt);
  engine.camera.setPosition(klipp.shot.position); // [x, y, z]
  engine.camera.setRotation(klipp.shot.quaternion); // [x, y, z, w]
  engine.camera.setFov(klipp.shot.fov); // degrees
  engine.render();
}
```

<Step>Add a virtual camera</Step>

A virtual camera is one shot, described by a **Body**, which decides where the camera is, and an **Aim**, which decides where it looks:

```ts
import { FollowBodyCore, HardLookAtAimCore } from '@kvvasuu/klipp';

const follow = klipp.addCamera('follow', { priority: 10 });
follow.body = new FollowBodyCore(player, { offset: [0, 3, 8] });
follow.aim = new HardLookAtAimCore(player);
```

The camera now stays 8 units behind and 3 units above the box, looking straight at it.

<Step>Smooth it out</Step>

`damping` lets the camera lag behind a little instead of being glued to the box. The value is roughly how many seconds it takes to catch up:

```ts
follow.body = new FollowBodyCore(player, { offset: [0, 3, 8], damping: 0.5 });
```

<Step>Add a second shot</Step>

A wide overview camera with a higher `priority`, turned on and off with `active`:

```ts
import { HardLockToTargetBodyCore } from '@kvvasuu/klipp';

const above = createTargetPose();
vec3.set(above.position, 0, 15, 15);
const center = createTargetPose();

const overview = klipp.addCamera('overview', { priority: 20, active: false });
overview.body = new HardLockToTargetBodyCore(above);
overview.aim = new HardLookAtAimCore(center);

button.onclick = () => {
  overview.active = !overview.active;
};
```

The highest-priority active camera is the one on screen. Toggle `overview` and klipp blends between the two shots.

<Step>Change the blend</Step>

By default a blend takes 2 seconds with an ease-in-out curve:

```ts
import { BlendCurves } from '@kvvasuu/klipp';

const klipp = new KlippCore({ defaultBlend: { curve: BlendCurves.easeInOut, time: 0.8 } });
```

<Steps>

<Step>Create klipp</Step>

`Klipp` drives a three.js camera:

```ts title="main.ts"
import { GridHelper, PerspectiveCamera, Scene, WebGLRenderer } from 'three';
import { Klipp } from '@kvvasuu/klipp/three';

const renderer = new WebGLRenderer();
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

const scene = new Scene();
scene.add(new GridHelper(20, 20));
const camera = new PerspectiveCamera(50, innerWidth / innerHeight);

const klipp = new Klipp(camera);
klipp.setSize(innerWidth, innerHeight);
```

`setSize` matters for pieces that frame by screen position, like the composers. Call it again whenever the viewport resizes.

<Step>Add a moving box</Step>

Any `Object3D` can be a target. `klipp.update` writes the shot to the camera:

```ts
import { BoxGeometry, Mesh, MeshNormalMaterial } from 'three';

const player = new Mesh(new BoxGeometry(), new MeshNormalMaterial());
scene.add(player);

let last = 0;
renderer.setAnimationLoop((time) => {
  const t = time / 1000;
  player.position.set(Math.sin(t) * 4, 0.5, Math.cos(t) * 4);

  klipp.update(t - last);
  last = t;
  renderer.render(scene, camera);
});
```

<Step>Add a virtual camera</Step>

A virtual camera is one shot, described by a **Body**, which decides where the camera is, and an **Aim**, which decides where it looks:

import { FollowBody, HardLookAtAim } from '@kvvasuu/klipp/three';

<Step>Add a second shot</Step>

import { HardLockToTargetBody } from '@kvvasuu/klipp/three';

const overview = klipp.addCamera('overview', { priority: 20, active: false });

  overview.active = !overview.active;

<Steps>

<Step>Start with a scene</Step>

A box that moves in a circle. A ref to it will be the target:

```tsx title="App.tsx"
import { useRef } from 'react';
import { Canvas, useFrame } from '@react-three/fiber';
import type { Mesh } from 'three';

function Player({ ref }) {
  useFrame(({ clock }) => {
    const t = clock.getElapsedTime();
    ref.current.position.set(Math.sin(t) * 4, 0.5, Math.cos(t) * 4);
  });

  return (
    <mesh ref={ref}>
      <boxGeometry />
      <meshNormalMaterial />
    </mesh>
  );
}

export default function App() {
  const playerRef = useRef<Mesh>(null);

  return (
    <Canvas>
      <Player ref={playerRef} />
      <gridHelper args={[20, 20]} />
    </Canvas>
  );
}
```

<Step>Add `<Klipp>`</Step>

`<Klipp>` drives the camera. Put it anywhere inside `<Canvas>`:

```tsx
import { Klipp } from '@kvvasuu/klipp/react';

<Canvas>
  <Klipp>{/* cameras go here */}</Klipp>
  <Player ref={playerRef} />
</Canvas>
```

<Step>Add a virtual camera</Step>

A `<VirtualCamera>` is one shot, described by a **Body**, which decides where the camera is, and an **Aim**, which decides where it looks:

```tsx
import { Klipp, VirtualCamera, Body, Aim } from '@kvvasuu/klipp/react';

<Klipp>
  <VirtualCamera name="follow" priority={10}>
    <Body.Follow target={playerRef} offset={[0, 3, 8]} />
    <Aim.HardLookAt target={playerRef} />
  </VirtualCamera>
</Klipp>
```

The camera now stays 8 units behind and 3 units above the box, looking straight at it.

<Step>Smooth it out</Step>

`damping` lets the camera lag behind a little instead of being glued to the box. The value is roughly how many seconds it takes to catch up:

```tsx
<Body.Follow target={playerRef} offset={[0, 3, 8]} damping={0.5} />
```

<Step>Add a second shot</Step>

A wide overview camera with a higher `priority`, turned on and off with `active`. A target can also be a fixed point, `[x, y, z]`:

```tsx title="App.tsx" collapsible
import { useRef, useState } from 'react';
import { Canvas } from '@react-three/fiber';
import type { Mesh } from 'three';
import { Klipp, VirtualCamera, Body, Aim } from '@kvvasuu/klipp/react';

export default function App() {
  const playerRef = useRef<Mesh>(null);
  const [overview, setOverview] = useState(false);

  return (
    <>
      <button onClick={() => setOverview(!overview)}>Toggle overview</button>
      <Canvas>
        <Klipp>
          <VirtualCamera name="follow" priority={10}>
            <Body.Follow target={playerRef} offset={[0, 3, 8]} damping={0.5} />
            <Aim.HardLookAt target={playerRef} />
          </VirtualCamera>

          <VirtualCamera name="overview" priority={20} active={overview}>
            <Body.HardLockToTarget target={[0, 15, 15]} />
            <Aim.HardLookAt target={[0, 0, 0]} />
          </VirtualCamera>
        </Klipp>
        <Player ref={playerRef} />
        <gridHelper args={[20, 20]} />
      </Canvas>
    </>
  );
}
```

The highest-priority active camera is the one on screen. Toggle `overview` and klipp blends between the two shots.

<Step>Change the blend</Step>

By default a blend takes 2 seconds with an ease-in-out curve:

```tsx
import { BlendCurves } from '@kvvasuu/klipp';

<Klipp defaultBlend={{ curve: BlendCurves.easeInOut, time: 0.8 }}>
```
