<Intro>
  Describe the shots you want. **klipp** picks the right one and smoothly blends between them.
</Intro>

```bash
npm install @kvvasuu/klipp
```

> [!WARNING]
> Early-stage and experimental. The API may still change.

> [!TIP]
> See it in action on the [examples site](https://kvvasuu.github.io/klipp/examples/).

## Why klipp?

Most 3D projects rebuild the same camera code: an offset that follows the player, damping, a dead zone, a cutscene camera and a smooth way back. klipp brings the virtual camera model from engines like Unity to the web: each shot is described on its own, the one with the highest priority is on screen, and switching between shots is a blend.

## One system, any renderer

The core is a complete camera system with no renderer or framework attached. Integrations are thin layers on top of it: three.js and React Three Fiber today, with more to come, like TresJS. Each page shows the core and every integration in tabs.

## What it looks like

A follow camera, and a cutscene camera that takes over when it turns on. Turning it off blends back.

```ts
import { vec3 } from 'math';
import { Klipp, FollowBody, HardLockToTargetBody, HardLookAtAim, createTargetPose } from '@kvvasuu/klipp';

const klipp = new Klipp();
const player = createTargetPose(); // keep player.position up to date
const spot = createTargetPose();
vec3.set(spot.position, 10, 2, 0);

const follow = klipp.addCamera('follow', { priority: 10 });
follow.body = new FollowBody(player, { offset: [0, 3, 8], damping: 0.5 });
follow.aim = new HardLookAtAim(player);

const cutscene = klipp.addCamera('cutscene', { priority: 20, active: false });
cutscene.body = new HardLockToTargetBody(spot);
cutscene.aim = new HardLookAtAim(player);

// every frame
klipp.update(dt);
engineCamera.setPosition(klipp.shot.position);
engineCamera.setRotation(klipp.shot.quaternion);
```
