Free look-around. `pan` turns the camera left and right, `tilt` up and down, both in degrees. Add an [`<InputController>`](/input/input-controller) inside it to drive them with the mouse or touch.

```tsx
import { Aim, Body, InputController } from '@kvvasuu/klipp/react';

<VirtualCamera name="first-person" priority={10}>
  <Body.HardLockToTarget target={headRef} />
  <Aim.PanTilt>
    <InputController
      mouseButtons={{ left: { axes: { x: 'pan', y: 'tilt' }, gain: 0.15 } }}
      touches={{ one: { axes: { x: 'pan', y: 'tilt' }, gain: 0.15 } }}
    />
  </Aim.PanTilt>
</VirtualCamera>
```

## Props

| Prop | Description | Default |
| ---- | ----------- | ------- |
| `target` | Makes `pan` and `tilt` relative to this object's rotation, for example a vehicle's cockpit. Omit for world space. | |
| `panRange` | Pan limits, in degrees. | `[-180, 180]` |
| `tiltRange` | Tilt limits, in degrees. | `[-90, 90]` |
| `panWrap` | Loop around at the edges of `panRange` instead of stopping. | `true` |
| `tiltWrap` | Loop around at the edges of `tiltRange` instead of stopping. | `false` |
| `damping` | Seconds to catch up with the input. See [Damping](/getting-started/core-concepts#damping). | `0` |
| `maxSpeed` | Maximum turn speed, in degrees per second. | `Infinity` |
| `recentering` | Return to the center after a while without input. See [Input Axis](/input/input-axis#recentering). | off |
| `autoNormalize` | Keep `pan` inside `panRange` after each drag while `panWrap` is on. | `false` |

To start facing a specific direction, pass a `quaternion` to the camera's [`initialState`](/api/virtual-camera#initialstate).

## Driving it from code

`ref` gives you the `PanTiltAim`. Its `pan` and `tilt` are [`InputAxis`](/input/input-axis) instances you can drive directly:

```tsx
const aim = useRef<PanTiltAim>(null);

aim.current.pan.applyDelta(5); // turn right by 5°
aim.current.tilt.value;        // current tilt
```
