Free look-around. `pan` turns the camera left and right, `tilt` up and down, both in degrees. Each one is an [`InputAxis`](/input/input-axis), so it can be driven by the mouse and touch through an [input controller](/input/input-controller), or from code, for example in a cutscene.

To start facing a specific direction, pass a `quaternion` to the camera's [`initialState`](/api/virtual-camera#initialstate).

## Settings

On the core and in three.js, these are set on the axes: `aim.pan` and `aim.tilt`.

| Setting | Description | Default |
| ------- | ----------- | ------- |
| `target` | Makes `pan` and `tilt` relative to this target's rotation, for example a vehicle's cockpit. Omit for world space. | |
| `panRange`, `tiltRange` | Limits, in degrees. `range` on an axis. | `[-180, 180]`, `[-90, 90]` |
| `panWrap`, `tiltWrap` | Loop around at the edges of the range instead of stopping. `wrap` on an axis. | `true`, `false` |
| `damping` | Seconds to catch up with the input. See [Damping](/getting-started/core-concepts#damping). | `0` |
| `maxSpeed` | Maximum turn speed, in degrees per second. | `Infinity` |
| `recentering` | Return to the center after a while without input. See [InputAxis](/input/input-axis#recentering). | off |
| `autoNormalize` | Keep `pan` inside its range after each drag while it wraps. | `false` |

```ts
import { PanTiltAim } from '@kvvasuu/klipp';
import { InputAxisController } from '@kvvasuu/klipp/dom';

const aim = new PanTiltAim();
aim.tilt.range = [-60, 60];
camera.aim = aim;

const input = new InputAxisController({
  mouseButtons: { left: { axes: { x: aim.pan, y: aim.tilt }, gain: 0.15 }, right: null, middle: null },
  touches: { one: { axes: { x: aim.pan, y: aim.tilt }, gain: 0.15 }, two: null, three: null },
});
klipp.whileOnScreen(camera, () => {
  input.connect(canvas);
  return () => input.disconnect();
});
klipp.registerUpdate(() => input.update()); // reads input before the cameras run
```

Pass a target to make `pan` and `tilt` relative to its rotation: `new PanTiltAim(vehicle)`.

**From code**

```ts
aim.pan.applyDelta(5); // turn right by 5°
aim.tilt.value;        // current tilt
```

Add an [`<InputController>`](/input/input-controller) inside it to drive it with the mouse or touch:

```tsx
import { Aim, Body, InputController } from '@kvvasuu/klipp/react';

<VirtualCamera name="first-person" priority={10}>
  <Body.HardLockToTarget target={headRef} />
  <Aim.PanTilt tiltRange={[-60, 60]}>
    <InputController
      mouseButtons={{ left: { axes: { x: 'pan', y: 'tilt' }, gain: 0.15 } }}
      touches={{ one: { axes: { x: 'pan', y: 'tilt' }, gain: 0.15 } }}
    />
  </Aim.PanTilt>
</VirtualCamera>
```

`ref` gives you the `PanTiltAimThree`.

**From code**

```tsx
const aim = useRef<PanTiltAimThree>(null);

aim.current.pan.applyDelta(5); // turn right by 5°
aim.current.tilt.value;        // current tilt
```
