---
title: HardLookAt
description: Always looks straight at the target.
nav: 31
---

Rotates the camera so the target is always in the center of the screen.

```tsx
<VirtualCamera name="follow" priority={10}>
  <Body.Follow target={playerRef} offset={[0, 3, 8]} damping={0.5} />
  <Aim.HardLookAt target={playerRef} />
</VirtualCamera>
```

## Props

| Prop | Description | Default |
| ---- | ----------- | ------- |
| `target` | What to look at. See [Targets](/getting-started/core-concepts#targets). | |

`HardLookAt` is always instant. For a smooth look-at, use [`RotationComposer`](/aim/rotation-composer) with `damping`:

```tsx
<Aim.RotationComposer target={playerRef} damping={0.3} />
```

`ref` gives you the `HardLookAtAim`.
