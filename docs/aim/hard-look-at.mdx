Rotates the camera so the target is always in the center of the screen. It's always instant. For a smooth look-at, use [`RotationComposer`](/aim/rotation-composer) with `damping`.

## Core

```ts
import { HardLookAtAimCore } from '@kvvasuu/klipp';

camera.aim = new HardLookAtAimCore(player);
```

Which way is up comes from the Body, for example from Follow's [`bindingMode`](/body/follow#bindingmode).

## React Three Fiber

```tsx
<VirtualCamera name="follow" priority={10}>
  <Body.Follow target={playerRef} offset={[0, 3, 8]} damping={0.5} />
  <Aim.HardLookAt target={playerRef} />
</VirtualCamera>
```

`ref` gives you the `HardLookAtAim`.

## Settings

| Setting | Description | Default |
| ------- | ----------- | ------- |
| `target` | What to look at. See [Targets](/getting-started/core-concepts#targets). | |
