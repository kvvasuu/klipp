---
title: Aim
description: Decides where the camera looks.
nav: 30
---

An Aim rotates the camera. It never moves it, that's the [Body](/body/introduction)'s job. Each `<VirtualCamera>` has at most one Aim, and it always runs after the Body.

```tsx
import { VirtualCamera, Body, Aim } from '@kvvasuu/klipp/react';

<VirtualCamera name="follow" priority={10}>
  <Body.Follow target={playerRef} offset={[0, 3, 8]} />
  <Aim.HardLookAt target={playerRef} />
</VirtualCamera>
```

## Which one?

| Aim | Use it for |
| --- | ---------- |
| [`HardLookAt`](/aim/hard-look-at) | Always looking straight at a target. |
| [`RotationComposer`](/aim/rotation-composer) | Looking at a target smoothly, with a dead zone or off-center framing. |
| [`RotateWithFollowTarget`](/aim/rotate-with-follow-target) | Copying a target's rotation: first person, mounted cameras. |
| [`PanTilt`](/aim/pan-tilt) | Letting the user look around with the mouse or touch. |

Without an Aim the camera keeps its [`initialState`](/api/virtual-camera#initialstate) rotation.
