---
title: RotateWithFollowTarget
description: Copies the target's rotation.
nav: 33
---

Gives the camera the same rotation as the target, as if it were glued to it. It doesn't look at the target, it only copies how the target is turned.

## Settings

| Setting | Description | Default |
| ------- | ----------- | ------- |
| `target` | Whose rotation to copy. Must have one; a fixed point doesn't. See [Targets](/getting-started/core-concepts#targets). | |
| `damping` | Seconds to catch up with the target's rotation. `0` is instant. See [Damping](/getting-started/core-concepts#damping). | `0` |
| `maxSpeed` | Maximum turn speed, in radians per second. | `Infinity` |

```ts
import { HardLockToTargetBody, RotateWithFollowTargetAim } from '@kvvasuu/klipp';

camera.body = new HardLockToTargetBody(head);
camera.aim = new RotateWithFollowTargetAim(head, { damping: 0.1 });
```

Only `head.rotation` is read, and only while `head.hasRotation` is set.
